推荐

A · 烟熏玻璃

深色烟熏底 + 30px 模糊，白字在任何桌面背景下都有稳定对比度。最接近“液态玻璃”的深色形态。

  • 白色桌面上不再出现白字白底，详情逐行可读
  • 青色只留给音标、词性和少量强调，层级清楚
  • 适合作为默认方案，长时间显示不抢眼
在对话里回复方案名（如「A」）即按该方案落地到真实组件。

这一版同时修掉的显示问题

日间可读性玻璃底色加深/加墨，文字不再依赖桌面颜色，白色壁纸下也清晰。
详情不再被裁悬停时头部收窄，详情占满窗口剩余高度，内部滚动而不是溢出 520px。
层级与留白单词 31px、音标 13.5px、正文 12.8px，分组、标题、正文、注释四级分明。
例句可扫读英文例句与中文译文分两行；短语英文高亮、释义弱化，扫一眼就懂。
