# 免费词典

添加单词时会立即查询随项目附带的 ECDICT 本地词库，保存中文释义、词性与音标；无需账号、Key 或网络。
随后只向 Free Dictionary API 发送当前英文单词，补充可用的英文例句与发音地址。接口并非每个词都有例句或发音，未提供的字段保持为空。
接口失败或限流不会阻止添加单词，不会删除已有释义，也不会自动重试；限流时遵守 Retry-After，最少等待 60 秒。
免费词典的例句通常只有英文，缺少中文译文时显示「中文翻译待补全」，不会标记为内容已完整。在词库中点击「补全」或「一键补全」，配置的 AI 会为原句补上中文翻译，保留已有英文、已翻译的例句及自定义释义。不会在后台自动调用 AI。

## 操作

- 「快速添加」：先保存本地词条，在线内容在后台补充，完成后自动更新页面。
- 「免费查词预览」：预览本地释义和在线内容，确认后完整保存。
- 「词库 → 查词」：为已有词条补充缺少的字段，保留已有中文释义和双语例句。
- 「AI 补全」：配置 LLM 后出现，手动补充双语短语、例句与未收录的词汇。不会自动调用收费模型。
- 音标旁始终提供发音按钮：优先播放词典录音；未提供录音或加载失败时，使用 Windows 已安装的英文语音本地朗读，支持单词和短语。词典录音需要网络，本地朗读不需要网络或 API Key；首次准备语音可能需要片刻，之后在本次运行中缓存。
- 详情底部保留词库、词条、音频来源以及接口返回的许可证链接。

## 数据与更新

`resources/dictionary/` 包含按首字母分片的压缩词库、ECDICT 的 LICENSE 和来源元数据。程序按需解压，最多缓存四个分片，不在启动时加载完整词库。

需要重新生成时执行：

```sh
npm run dictionary:prepare
```

该脚本使用固定版本的 ECDICT，生成元数据时记录原始 CSV 的 SHA-256。也可先下载对应版本的 CSV 与 LICENSE，再离线导入：

```sh
node scripts/prepare-dictionary.mjs /path/to/ecdict.csv /path/to/LICENSE
```

来源：

- ECDICT：<https://github.com/skywind3000/ECDICT>（MIT；保留随附 LICENSE）
- Free Dictionary API：<https://dictionaryapi.dev/>；只读、免鉴权的 `GET https://api.dictionaryapi.dev/api/v2/entries/en/<word>`。

Free Dictionary API 的词条、例句和发音可能来自不同来源；许可信息按每次响应保存并展示。当前只查询英文端点，不将英文释义冒充中文释义。公共接口的可用性不影响本地查词。
